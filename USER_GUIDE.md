## 🎯 **How to Experience All Features**

### **As a Teacher** (`teacher@demo.com`):

1. **📊 Dashboard Overview**
   - View class statistics
   - See recent submissions
   - Monitor upcoming deadlines

2. **📈 Analytics Dashboard**
   - Click "ANALYTICS" in top navigation
   - View comprehensive performance metrics
   - See grade distributions and trends

3. **🏫 Manage Classrooms**
   - Click on any classroom card
   - View enrolled students
   - See classroom analytics

4. **📝 Create New Assignments**
   - Go to classroom detail page
   - Click "Create Assignment"
   - Set due dates, points, rubrics

5. **🎯 Grade Submissions**
   - Click "GRADING" in navigation
   - Select assignment to grade
   - Provide feedback and scores

6. **📁 File Management**
   - Upload assignment materials
   - Download student submissions

### **As a Student** (any student account):

1. **📚 View Assignments**
   - See all published assignments
   - Check due dates and requirements
   - Track submission status

2. **📤 Submit Work**
   - Click "Submit Assignment" 
   - Add text content
   - Upload files (drag & drop)

3. **📊 Track Progress**
   - View personal analytics
   - Check grades and feedback
   - Monitor upcoming deadlines

4. **🔔 Notifications**
   - Real-time updates on grades
   - Assignment reminders
   - Classroom activities

5. **🏫 Join New Classrooms**
   - Use class codes to join
   - Access multiple subjects
